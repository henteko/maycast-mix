# Maycast Mix — 機能仕様書

ブラウザで動作する、複数音声ファイルのカット編集・ミックス・MP3書き出しサービス。

---

## 1. プロダクト概要

| 項目 | 内容 |
| --- | --- |
| プロダクト名 | Maycast Mix |
| 提供形態 | ブラウザで動作する Web アプリ（インストール不要） |
| 想定ユースケース | ポッドキャスト・ラジオ番組の素材ミックス、SNS用音声編集 |
| 認証 | なし（毎回アップロードして使用する想定） |
| 永続化 | なし（リロードでセッション破棄。明示的に MP3 として書き出して保存する） |
| 対応ブラウザ | 最新の Chrome / Edge / Safari / Firefox |
| カラーモード | ライトモード |

---

## 3. トップバー

サービスのメタ情報とグローバルアクションを置く最上段の領域。

### 構成要素

- **ロゴ + サービス名**（`Maycast Mix`）
  - 控えめな表示。ブランド主張よりツール優先。
- **プロジェクトメタ**
  - セッション名（例: `untitled_session`）
  - トラック数
  - プロジェクト総尺
- **グローバルアクション**
  - 「音声を追加」ボタン … ファイル選択ダイアログから音声を追加
  - 設定ボタン
  - ヘルプボタン
  - **「MP3で書き出し」プライマリボタン** … 全トラックをミックスダウンしてダウンロード

---

## 4. トランスポートバー

再生制御・ツール選択・ズーム・選択コンテキストを集約した編集の中枢。

### 4.1 再生コントロール

| ボタン | 機能 |
| --- | --- |
| 先頭へ | 再生位置を 0 秒に戻す |
| 再生 / 一時停止 | スペースキーでも操作可能 |
| 末尾へ | 再生位置をプロジェクト末尾に移動 |
| ループ | 選択範囲または全体をループ再生 |

### 4.2 タイムコード表示

- 現在の再生位置と総尺を `MM:SS.ms` 形式で表示
- 等幅フォント（JetBrains Mono）

### 4.3 ツール切替（4種）

| ツール | 用途 |
| --- | --- |
| 選択（V） | クリップ・トラックの選択 |
| 移動（M） | クリップを左右にドラッグ移動 |
| **カット（C）** | **再生位置で、選択中のトラックを分割** |
| パン（H） | タイムラインを横にスクロール |

### 4.4 ズーム

- スライダー + ＋/− ボタン
- 表示倍率を `%` 表記で表示
- 範囲：40%〜300%

### 4.5 選択サマリー

選択状態のクリップ／トラックを示すコンテキストパネル。

- 「N トラック選択中」
- 現在の再生位置（カット対象位置）を併記
- クイックアクション：分割（再生位置で）／複製／削除

---

## 5. タイムルーラー

タイムラインの上部に固定表示される時間スケール。

- ズーム倍率に応じて目盛り間隔（5秒・10秒・15秒）を自動調整
- 主要目盛りに `MM:SS` ラベルを表示
- マイナー目盛りでミリ秒単位の位置感を提供

---

## 6. トラックヘッダ

各トラックの左側に固定表示されるコントロールパネル。

| 要素 | 機能 |
| --- | --- |
| カラーチップ | トラック識別色 |
| トラック名 | アップロードしたファイル名から自動設定 |
| メタ情報 | サンプリングレート・チャンネル数（例: `44.1 kHz · Stereo`） |
| M ボタン | ミュート（黄色で点灯） |
| S ボタン | ソロ（水色で点灯） |
| ボリュームスライダー | トラック単位の音量調整 |
| dB 値 | 現在の音量を dB 表示 |

選択中のトラックは左端にアクセントカラーのバー、ヘッダ全体に淡いアクセント背景が入る。

---

## 7. タイムライン（波形エディタ）

### 7.1 トラックレーン

- 縦に複数のトラックが並ぶマルチトラック構成
- 各レーンの背景に縦のグリッド線（80px間隔）
- 選択中トラックのレーンは淡いアクセント色で塗られる

### 7.2 クリップ（音声ブロック）

- 1つのトラック内に複数のクリップを配置可能
- クリップ要素：
  - **ヘッダ部**：クリップ名 + 尺（`MM:SS`）
  - **波形部**：ピーク値を縦バーで描画（Descript系）
  - 選択中はアクセントカラーの太いボーダー＋影
- トラックごとに固有のクリップ色・波形色

### 7.3 再生ヘッド（プレイヘッド）

- 赤い縦線でタイムライン全幅を貫く
- 上部に三角インジケータ＋現在のタイムコードを表示
- ルーラー上をクリックして任意位置へジャンプ

### 7.4 末尾の「音声を追加」レーン

タイムライン末尾に常に表示される追加用レーン。

- 「+ 音声を追加」ボタン
- ファイルをドラッグ&ドロップ可能
- ショートカット `⌘O` 提示
- 対応形式：MP3 / WAV / M4A

---

## 8. 主要操作仕様

### 8.1 ファイルの読み込み

| 方法 | 操作 |
| --- | --- |
| ボタン | トップバー「音声を追加」または末尾レーンのボタン |
| ドラッグ&ドロップ | タイムライン領域に直接ドロップ |
| キーボード | `⌘O` / `Ctrl+O` |

複数ファイル同時読み込みに対応。読み込んだ音声は新規トラックとして末尾に追加される。

### 8.2 複数選択

- 選択ツールでクリップをクリックで選択
- `Shift+クリック` で追加選択
- `⌘+クリック` でトグル選択
- ドラッグでラバーバンド選択（複数クリップを範囲で選択）
- トラックヘッダのクリックでトラック全体を選択

### 8.3 カット（分割）

**再生位置で選択中のトラックを分割する。**

| 動作フロー |
| --- |
| 1. 編集したいトラック（複数可）を選択 |
| 2. 再生またはルーラークリックで再生位置を分割したい時刻に合わせる |
| 3. カットツールに切替、または `⌘B` を押下、または選択サマリーの「分割」ボタン |
| 4. 選択中の各トラックで、再生位置を含むクリップが2つに分割される |

UI フィードバック：
- カットツール選択中、選択中トラックのクリップ上の再生ヘッド位置に**赤い分割ライン**＋「分割」ラベルがプレビュー表示される
- 分割対象外のトラックには表示されない

### 8.4 波形のドラッグ移動

- 移動ツールを選択
- クリップをドラッグして、同一トラック内・別トラックへ自由に移動
- スナップ：他クリップの端、再生位置に吸着（オン/オフ可能）

### 8.5 削除

- 選択中のクリップに `Delete` / `Backspace`
- 選択サマリーのゴミ箱ボタン
- クリップが消えた領域は無音となる（他クリップは詰めない）

### 8.6 再生プレビュー

- スペースキーで再生／一時停止
- 全トラックをリアルタイムにミックスして再生
- ミュート・ソロ・音量設定が反映される
- ループON時は選択範囲または全体をループ

### 8.7 ズーム / スクロール

| 操作 | 結果 |
| --- | --- |
| トランスポートのズームスライダー | 全体ズーム |
| `⌘+スクロール` | カーソル位置を中心にズーム |
| マウスホイール / トラックパッド横スワイプ | 横スクロール |
| パンツール + ドラッグ | 横スクロール |

## 9. ステータスバー

画面最下部に常時表示される情報行。

- 状態インジケータ（緑のパルス + 状態テキスト）
- プロジェクトのオーディオ仕様（サンプルレート・ビット深度・チャンネル）
- 総サンプル数
- エクスポート設定（例: `MP3 320kbps`）
- CPU 使用率の目安

---

## 10. MP3 書き出し

### 10.1 トリガー

トップバー右端の「MP3で書き出し」ボタン。

### 10.2 出力仕様

- 形式：MP3
- ビットレート：320 kbps（既定。設定で変更可能）
- サンプルレート：44.1 kHz
- チャンネル：ステレオ
- 出力範囲：プロジェクト全体（選択範囲のみのオプションも提供）

### 10.3 処理フロー

1. ボタン押下
2. 全トラックを内部でミックスダウン
3. MP3 にエンコード（ブラウザ内で完結）
4. 完了するとファイルダウンロードがトリガーされる
5. ファイル名：`maycast-mix_<セッション名>_<タイムスタンプ>.mp3`

サーバーへのアップロードは行わない。すべてブラウザ内で完結する。

## 13. 非機能要件

- **パフォーマンス**：5トラック × 5分の素材を 60fps でスクロール・ズームできること
- **応答性**：1440px の横幅を最低保証。それより狭い場合は横スクロール
- **オーディオ品質**：内部処理は 44.1 kHz / 32-bit float、書き出し時に 16-bit へダウンミックス
- **プライバシー**：音声データはブラウザ外に送信しない
- **永続化なし**：リロードでセッション破棄を明示的に伝える（書き出し前の確認ダイアログ推奨）
